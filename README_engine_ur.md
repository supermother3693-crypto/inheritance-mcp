    python -m faraid cases/dudha_72576.txt -o output/dudha.xlsx --pdf
    python tests/test_cases.py        # چاروں نمونوں سے خودکار تصدیق

## مسئلہ لکھنے کا فارمیٹ (cases/*.txt)
- ہر بطن `مورث: نام | وفات: تاریخ | جنس: مرد/عورت` سے شروع (مورثہ: بھی چلتا ہے)۔
- پھر `رشتہ: نام، نام` (بیوی، شوہر، باپ، ماں، دادا، نانی، دادی، بیٹا، بیٹی، پوتا، پوتی، بھائی، بہن، علاتی/اخیافی، بھتیجا، چچا، چچازاد ...)۔
- دوسرے بطن کا مورث وہی نام جو پہلے وارث بنا۔ ایک ہی نام کے دو افراد ہوں تو `نام#نشانی`۔
- `زبان: ur` یا `gu` (رشتوں کے الفاظ و تمہید)۔

## انجن کیا کرتا ہے
حجب → فرض/عصبہ (بنفسہ، بالغیر، مع الغیر) → اصل → عول/رد (چاروں اقسام) → تصحیح (مضروب) →
مناسخہ (ما فی الید، تماثل/تداخل/توافق/تباین، وفق، مضروب، جامعہ) → آخری سہام → تصدیق۔
روپے کا حساب شامل نہیں (حصہ B بند)۔

## حدود (انجن خود رک کر بتاتا ہے، اندازہ نہیں لگاتا)
- ذوی الارحام کا حساب فعال نہیں۔
- دادا کے ساتھ بھائی بہن: امام ابو حنیفہؒ کا قول (بھائی بہن محروم) — مقاسمہ فعال نہیں؛ نوٹ میں اختلاف لکھا آتا ہے۔
- پوتا/پوتی صرف بیٹے کے بیٹے/بیٹی (پڑپوتے نہیں)؛ بھتیجے/چچا کے نچلے درجے، مولیٰ، حمل، مفقود، خنثیٰ شامل نہیں۔
